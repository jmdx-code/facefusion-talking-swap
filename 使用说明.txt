FaceFusion 3.9.0 Windows NVIDIA 独立便携版（含云表格协同任务中心）
====================================================================

使用条件
1. Windows 10/11 64位（无需安装 Python、CUDA 或 FFmpeg，运行环境全部内置）。
2. NVIDIA 显卡并已安装官方显卡驱动（建议 8GB 及以上显存）。
3. 建议 16GB 以上内存，预留至少 15GB 磁盘可用空间用于模型缓存与长视频处理。

首次启动与自动环境/模型初始化
1. 为实现秒级分发，初始分享包（仅约 14 MB）内置最小化 Python 3.12 核心启动器与全套口播换脸工作台代码。
2. 首次双击“后台启动FaceFusion.cmd”（或“启动FaceFusion.cmd”）时，控制台会自动从官方国际源（GitHub Official Releases / PyPI / HuggingFace）依次安装 FFmpeg、Python 与 NVIDIA CUDA 12 / cuDNN 9 运行库及所需 AI 模型（`userdata\models\`），全程支持字节级断点续传与 SHA-256 / CRC32 校验（下载一次永久缓存，后续启动秒开）。
3. 每次启动时会自动检测 GitHub 最新版本并秒级同步约 0.4 MB 的代码热更新包（也可点击网页右上角“🔄 检查在线热更新”或双击“一键检查更新.cmd”），个人授权与已下载环境/模型均完好保留。

日常使用
1. 双击“后台启动FaceFusion.cmd”（或“启动FaceFusion.cmd”）。
2. 等待浏览器自动打开 http://127.0.0.1:7860。
3. 顶部提供两个切换页签：
   - 【🎬 手动精细换脸】：极简三步操作（① 上传源人脸图与目标视频 -> ② 一键选择场景效果 -> ③ 点击开始处理），默认输出在 `userdata\manual_outputs`（支持一键打开保存目录；专业参数折叠在底部“高级参数微调”中，日常无需改动）。
   - 【📋 云表格任务中心】：对接 Google Sheets 多人协同接单、按需标准化转码、换脸、上传 Google Drive 并自动回填共享链接。
4. 使用完毕双击“停止FaceFusion.cmd”。

目录隔离与两种分发打包方式
- 本机所有个人数据、Google OAuth 登录凭证、自定义场景预设、首次自动下载的模型权重（`userdata\models`）、运行日志、临时缓存及本地留存成品，全部集中在根目录下的 `userdata` 文件夹中，启动时自动创建，不会修改系统目录或注册表，也不会自动读取电脑主机名。
- 给团队成员分发或日常发版更新时：
  - 维护者一键发版（最省心）：修改代码后双击“一键发布热更新.cmd”，数秒内即可自动递增版本号、生成 ~0.4 MB 热更新包与 ~14 MB 初始包并发布到 GitHub Releases；所有已安装成员下次启动软件会自动秒级热更新。
  - 本地离线打包：双击“打包分享版.cmd”会在 `userdata\dist\` 下生成 `FaceFusion-Portable-Windows-NVIDIA.zip`（约 14 MB，给新成员首次安装）与 `FaceFusion-Update-CodeOnly.zip`（约 0.4 MB，给老成员覆盖升级）。

一、手动精细换脸与场景参数预设
- ✨ 没问题选这个：默认推荐参数，InSwapper FP16 + 上下半脸恢复80 + GFPGAN混合65。
- 👄 解决嘴巴张不开：InSwapper FP16 + 仅下半脸恢复100 + GFPGAN混合30。
- 👀 解决眼睛斜：在正常参数基础上关闭上半脸恢复；下半脸恢复80、GFPGAN混合65。
- 可展开“更多预设 / 保存自定义预设”命名保存（保存在 `userdata\facefusion-presets.json`）。

二、云表格任务中心使用说明
1. 首次配置（按界面 1 → 2 → 3 步完成，连接成功后设置面板会自动收起，配置保存在 `userdata\` 下）：
   - 第 1 步：必填自定义“本机工位名称”（如：Alex、Worker-01；程序不会读取您的电脑名称，由用户自行设置）。
   - 第 2 步：上传 Google Cloud 下载的 OAuth 2.0 客户端授权文件（Desktop App 类型 `client_secret.json`，上传一次自动保存），点击“🔑 登录 Google”完成浏览器授权（若默认浏览器未自动弹出，可直接点击第 2 步出现的蓝色登录按钮；若浏览器代理扩展拦截了 127.0.0.1 导致允许后页面无法跳转，复制浏览器地址栏整串网址粘贴到备用输入框即可立即完成授权；如需切换账号点击“解绑账号”）。
   - 第 3 步：粘贴 Google Sheets 完整网址，点击“✅ 保存配置并连接表格”（如需指定页签或自定义成品 Google Drive 文件夹，可展开下方“可选高级项”，默认留空自动识别/自动创建“FaceFusion_自动换脸成品”文件夹）。
2. 表格格式要求（支持任意移动列顺序、插入删除行或排序）：
   - 第 1 行表头包含“源人脸图片”和“目标视频”（可选列：“场景预设”）。
   - 系统会自动维护“任务编号”、“任务状态”、“领取节点”、“成品链接”、“处理备注”列。
   - 每次读写前按第 1 行标签定位列；领取需求时脚本自动生成唯一任务编号，完成回写时按任务编号反查当前所在行，挪列插行均不受影响。
   - 表格端仅写入“已领取制作中”及最终的“已完成”/“制作失败”，不刷中间状态。
3. 两种接单方式与本地留档：
   - 手动选择领取：点击“刷新表格需求”，勾选任意多条待领需求点击“手动领取选中需求”（不限数量；若某条刚被其他成员抢先领取，会自动跳过并提示；也可勾选显示“制作失败”的需求重新制作）。
   - 自动接单模式：勾选“开启自动接单”，每间隔 20 分钟读取表格自动补单，最多只保持 2 条活跃任务（1 条制作中 + 1 条排队中），达到饱和即停止领新单。重启软件默认关闭自动接单。
   - 本地留档与队列退回：成品上传成功后，`userdata\sheet_outputs` 默认自动保留最近 10 条成品视频（超出自动清理最旧文件），可点“打开本地成品目录”查看；未开始的排队任务支持单条或全部退回表格；若上传时网络中断，成品会保底存至 `userdata\sheet_saved_outputs`，网络恢复后点“补传本地保底成品”即可免重跑直接上传回写。

注意事项
- 不要在程序运行时移动整个文件夹。
- 运行日志位于 `userdata\logs\facefusion-error.log`。
- 请只处理已获授权的人脸素材，并遵守当地法律及模型许可证。
